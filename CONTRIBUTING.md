# Contributing to Awesome Rocks

Thanks for your interest in contributing! This is a community-maintained list and
every addition, correction, and cleanup helps.

## Ways to contribute

- **Add a rock** — open a PR adding a row to the appropriate section.
- **Fix an error** — wrong hardness, broken link, typo, bad vibe. Open a PR.
- **Improve the docs** — this file, the style guide, templates.

Look for issues labeled
[`good first issue`](https://github.com/fcjr/good-first-issue/labels/good%20first%20issue)
if you're new here. They are scoped to be completable in a single small PR.

## Pull request checklist

- [ ] One logical change per PR (one rock, one fix, etc.)
- [ ] Rows follow the format in [docs/style-guide.md](docs/style-guide.md)
- [ ] Sections and rows are in alphabetical order
- [ ] Every rock has a `Source` link
- [ ] `npm run lint` passes locally
- [ ] PR description references the issue it closes (`Closes #123`)

## Running lint locally

```sh
npm install
npm run lint
```

## Code of conduct

Be kind. Rocks don't have feelings, but contributors do.
